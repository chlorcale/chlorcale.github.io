# Poxiao Pixel webfont

The bundled `poxiao-pixel-12px-square.woff2` is Poxiao Pixel 12px Square, obtained from the [FontPixel download page](https://fontpixel.com/en/fonts/poxiao-pixel/).

Poxiao Pixel is assembled from Fairfax, ZLabs Bitmap, and Galmuri. The upstream Poxiao Fonts forge identifies the font files as SIL Open Font License 1.1; see its [font repository and license](https://forge.poxiao-labs.work/Fonts/fzg). The font is bundled with this site under that license, not offered for sale by itself.
